# 0.1.72175 — Graph 색상 집합의 비트마스크 표현

Graph의 사용 중인 16색 계열을 하위 16비트로 기록한다. 새 색상을 고를 때마다 만들던 Set과 그 내부 저장 공간의 할당을 없앤다. shift의 입력은 0~15 색상 계열이며 행 번호·좌표·시간 값은 사용하지 않는다. 색상 선택 순서, 포화 시 충돌 점수, lane과 간선은 기존 규칙을 따른다.

## 정확성과 측정

0.1.72174 소스를 고정한 비교에서 전체 GraphData 52개, checkpoint 52개, 증분 결과 256개가 deep equality를 통과했다. 페이지 경계·가상 staged/working 행·이력 축소·임의 DAG를 포함한다. 15·16·17·32 병렬 lane의 색상 경계를 포함한 Node 테스트 19개, 타입 검사, production 빌드가 통과했다. 최초 계측 시안과 최종 제품 알고리즘의 번들 바이트도 일치했다.

최초 독립 수명 비교는 버전별 4개로 실행했다. 큰 편차와 악화된 중앙값이 있어 일반적인 CPU 개선 근거로 삼지 않았다. 모든 표본을 보존했다. 이어 짧은 동일 호출 수 구간에서 B/A와 A/B를 교대하는 pilot 및 최종 비교를 각각 독립 Node 수명 4개로 실행했다. 한 수명의 16개 block은 상관된 반복이며 먼저 수명별 중앙값을 계산한다. 아래는 최종 수명별 중앙값 4개의 중앙값이다. 측정 중 테스트·타입 검사·빌드를 병행하지 않았다.

| 합성 이력 / 행 | 전체 layout 경과 시간(ms) | Node CPU(ms) |
|---|---:|---:|
| linear / 300 | 0.1382 → 0.1287 | 0.1042 → 0.1046 |
| linear / 5,000 | 4.0732 → 3.7060 | 3.0269 → 3.0642 |
| merges / 300 | 0.1052 → 0.1037 | 0.0958 → 0.0951 |
| merges / 5,000 | 3.1953 → 3.1035 | 2.8837 → 2.8604 |
| wide / 300 | 0.2621 → 0.2483 | 0.2487 → 0.2320 |
| wide / 5,000 | 3.8022 → 3.6401 | 4.0077 → 3.8001 |

32개 병렬 lane 이력은 pilot과 최종의 8개 수명 모두 CPU 시간이 감소했다. 일반 이력의 방향은 섞였으며 전체 CPU 감소를 입증하지 않는다. 절감량은 layout 한 번당 밀리초 미만이다. Git 조회·브라우저 layout/paint·실제 VS Code 응답 시간을 이 수치에 포함하지 않는다. 머신이 바쁜 실제 업데이트 창의 응답 개선은 여전히 확인이 필요하다.

## 재현과 범위

프로젝트 루트에서 `node scripts/benchmark-graph-color-mask.mjs afd6b2eddc8ea01ee0a6306339253b935d4b6c5c /private/tmp/graph-color-mask.json`을 실행한다. 이 비교는 합성 데이터만 사용한다. 사용자 저장소를 읽거나 변경하지 않는다. 이번 버전의 시각 QA는 수행하지 않았다. 별도로 VSIX의 브라우저 자산과 설치된 runtime 바이트를 확인한다.
